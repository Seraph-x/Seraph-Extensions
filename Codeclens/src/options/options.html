基本

关闭后所有页面都不再自动识别，仅保留手动解码工具。
高亮模式使用 CSS Custom Highlight API；浏览器不支持时自动回退到 span 包裹。
页面异步加载新内容后自动重新扫描（单页应用建议开启）。
进入 Web Component 的 open shadow root 内部扫描（现代网站常用），会略微增加每次扫描的耗时。
不扫描 <pre> / <code> 内的内容，避免对源码本身做解码。

识别精度

越小越灵敏、误报越多；建议 10–16。
Base64 嵌套、Base64→Gzip→JSON 这类多层结构会被逐层解开。

识别类型

关闭不关心的格式可以显著降低误报。

站点黑名单

这些站点不会自动扫描（仍可右键手动解码）。

开发者

改完代码不用再手动刷新页面。

每 4 秒比对一次脚本指纹，一旦发现改动就自动重新注入到所有已打开的页面。改动 src/lib 与 src/content 下的文件即刻生效，无需刷新页面。
切换到新页面、单页应用（pushState）跳转、从后退缓存恢复时，自动确认页面脚本是否还活着，没接上就补注入一次。默认开启。
快捷键 Alt+Shift+R
会先卸载页面里的旧实例、再注入最新代码。页面本身不刷新，滚动位置和已填的表单内容都保留。
改动 background.js / manifest.json 后用这个。重载后已打开的页面会自动重新接上。
