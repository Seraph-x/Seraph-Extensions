# CodecLens · 页面编码识别与解码

自动扫描网页文本中的编码数据，就地标记，并通过悬浮卡片查看解码结果。也可在工具栏弹窗中粘贴文本，手动选择解码器。

当前版本 **1.2.0**，采用 Manifest V3，清单声明的 Chrome 最低版本为 **105**。本目录可直接加载，无需安装依赖或执行构建。

## 安装与更新

1. Chrome 打开 `chrome://extensions/`；Edge 打开 `edge://extensions/`。
2. 开启**开发者模式**，点击**加载已解压的扩展程序**。
3. 选择当前 `Codeclens/` 目录，即包含 [manifest.json](manifest.json) 的目录。
4. 打开或刷新目标网页，等待自动扫描；首次安装会打开设置页。
5. 点击工具栏图标查看页面结果，或进入「手动解码」。

本地演示页位于 [demo/demo.html](demo/demo.html)。使用浏览器打开时，需要先在扩展详情中允许访问文件网址。

更新文件后，可在扩展管理页重新加载扩展并刷新网页；已有的脚本重新注入功能见下文。

## 查看页面结果

- 将鼠标移到标记的编码片段上，查看类型、识别评分、原文及解码结果。
- 在悬浮卡片中复制结果；多层编码会展示链式解码路径，按 `Esc` 关闭卡片。
- 打开弹窗的**页面结果**页签，查看命中数量、扫描节点数和耗时。
- 使用类型／内容过滤框缩小结果范围，点击结果定位到页面，或点击**复制全部**。
- 点击弹窗顶部的重新扫描按钮，重新处理当前网页。

识别评分来自格式、可读性等启发式规则，不代表统计概率。二进制数据或短字符串可能不被自动识别，可以改用指定解码器。

### 三种展示方式

| 设置项 | 当前行为 |
| --- | --- |
| 高亮标记（默认） | 优先使用 CSS Custom Highlight API；不支持时使用 span 包裹 |
| 高亮并在原文后追加解码结果 | 保留编码原文，在后面追加解码文本 |
| 仅记录，不显示任何标记 | 当前实现会清空结果并停止页面扫描，并非后台继续记录 |

高亮 API 可用时无需包裹原文；追加模式和 span 高亮会修改页面 DOM。对依赖节点结构的网站，可关闭扫描或加入黑名单。

## 手动解码与支持格式

打开弹窗的**手动解码**页签，粘贴文本，选择自动识别或指定解码器，然后点击**执行**。也可以在网页上选中文字，使用右键菜单中的「CodecLens：解码选中文本」。右键链接菜单会尝试提取常见跳转参数中的编码。

| 格式 | 页面自动识别默认状态 | 说明 |
| --- | --- | --- |
| Base64 / Base64URL | 开启 | 例如 `aGVsbG8gd29ybGQ=` → `hello world` |
| Base58 / Base32 / Hex | 开启 | Hex 示例：`48656c6c6f` → `Hello` |
| JWT | 开启 | 展示 header、payload、签名字段及时间字段，不验证签名 |
| URL 编码 | 开启 | 例如 `%E4%BD%A0%E5%A5%BD` → `你好` |
| HTML 实体 | 开启 | 例如 `&lt;div&gt;` → `<div>` |
| Unicode 转义 | 开启 | 例如 `\u4f60\u597d` → `你好` |
| Data URI | 开启 | 页面扫描可提取并解码载荷，当前手动工具未提供完整 Data URI 的专门入口 |
| Ascii85 / ROT13 | 关闭 | 可在设置中开启自动识别，或直接指定解码器 |

手动工具提供 **Base64 编码**和 **URL 编码**两种反向操作。当前弹窗虽有「Base64URL 解码」选项，但未绑定对应的解码器导出，选择后会提示不支持；可通过自动识别或 Base64 解码处理。

### 压缩内容

对解码出的字节可识别 GZIP、ZLIB、BZIP2、ZSTD 的格式标记。出现「展开压缩流」按钮时，可在页面悬浮卡片中尝试解压。

当前解压实现仅支持浏览器 `DecompressionStream` 可用时的 GZIP 和 ZLIB 等 deflate 格式。**BZIP2、ZSTD 仅能识别，不能解压**，点击展开会显示不支持的错误。压缩层需要手动展开，并非自动完成所有解压与后续解码。

## 调整扫描设置

点击弹窗齿轮，或右键扩展图标打开选项。修改普通扫描设置后，点击**保存设置**；可用**恢复默认**重置。

| 设置 | 默认值 | 作用 |
| --- | --- | --- |
| 启用扫描 | 开启 | 全局控制页面扫描；关闭后仍可使用手动工具 |
| 展示方式 | 高亮标记 | 高亮、追加结果，或关闭页面扫描 |
| 监听动态内容 | 开启 | 网页新增或修改文本时重新扫描 |
| 扫描 Shadow DOM | 开启 | 扫描可访问的 open shadow root |
| 跳过代码块 | 关闭 | 开启后排除 pre / code 内容 |
| 候选串最小长度 | 12 | 设置页可调 6～40；更短的候选更容易误报 |
| 链式解码最大层数 | 4 | 设置页可调 1～8 |
| 识别类型 | 10 项开启 | 12 种类型独立开关，默认关闭 Ascii85、ROT13 |
| 站点黑名单 | 空 | 每行一个域名，支持星号通配 |

黑名单中，`example.com` 匹配该域名及其子域名，`*.example.com` 匹配子域名。被排除的页面不自动扫描，仍可尝试右键手动解码或弹窗工具。

设置页的**自检**区域可以载入示例或粘贴数据，查看当前配置下的识别和链式解码结果。

### 快捷键

| 默认快捷键 | 作用 |
| --- | --- |
| `Alt+Shift+D` | 临时切换当前标签页内容脚本的扫描状态，不写入全局设置 |
| `Alt+Shift+R` | 向已打开且允许注入的页面重新注入脚本 |

快捷键由浏览器分配；如有冲突，可在扩展管理页的快捷键设置中调整。

## 页面跳转与脚本更新

扩展监听动态 DOM、同页 URL 变化和前进后退缓存恢复。默认开启的**导航自动补注入**会在标签页加载完成或切换时检查内容脚本，必要时重新注入。

设置页的**开发者**区域提供：

| 功能 | 默认状态／用途 |
| --- | --- |
| 自动热重载 | 默认关闭；开启后定期比对 lib、content 脚本及内容样式的指纹，有变化时重新注入对应页面 |
| 导航自动补注入 | 默认开启；检查页面脚本是否可用 |
| 重新注入所有页面 | 卸载旧实例并加载当前脚本，页面本身不刷新 |
| 查看状态 | 显示版本、脚本指纹及页面连接情况 |
| 重载扩展 | 修改 background.js 或 manifest.json 后使用，重启后尝试恢复页面注入 |

弹窗或设置页文件修改后，应重新打开对应界面；页面内容脚本的重新注入不负责刷新这些界面。

## 常见问题与限制

**没有标记或结果。** 确认全局扫描已开启、展示方式不是「仅记录」、网站不在黑名单。检查识别类型和最小长度，尝试重新扫描；短串、随机字节或可读性较低的结果可能被规则过滤。

**换页或更新后失效。** 先尝试 `Alt+Shift+R` 或设置页的重新注入按钮。若仍无响应，刷新网页，并确认浏览器允许该网站上的扩展访问权限。

**本地演示页不工作。** 在扩展详情中允许访问文件网址，再打开或刷新演示页。

浏览器内部页、扩展商店等受限页面不能正常注入。当前自动脚本仅注入顶层页面，不覆盖 iframe；closed shadow root 无法扫描。大页面的扫描受节点及文本长度限制，不保证覆盖所有文本。

## 权限与数据

| 权限 | 用途 |
| --- | --- |
| `storage` | 保存扫描配置及开发者设置 |
| `contextMenus` | 提供选中文本、链接解码和扫描等右键菜单 |
| `clipboardWrite` | 复制解码结果 |
| `activeTab` / `scripting` | 操作当前页面及重新注入内容脚本 |
| `<all_urls>` | 在允许访问的网页中自动识别编码内容 |

编解码在浏览器本地完成，不把页面文本或解码结果发送到远程服务。普通设置保存在 `chrome.storage.sync`，开发者开关等状态保存在本地存储；热重载读取扩展自身的本地脚本文件。

## 目录结构

```text
Codeclens/
├── manifest.json
├── icons/                 扩展图标
├── demo/demo.html         本地演示页
├── src/
│   ├── background.js      右键菜单、快捷键、徽章与脚本注入
│   ├── lib/               配置工具、编解码与识别逻辑
│   ├── content/           页面扫描、高亮、悬浮卡片与内容样式
│   ├── popup/             页面结果与手动工具
│   └── options/           扫描设置、自检与开发者操作
└── README.md
```

核心实现见 [codecs.js](src/lib/codecs.js)、[detector.js](src/lib/detector.js) 和 [content.js](src/content/content.js)。版本以 manifest 为准，设置页页脚仍保留旧版本文字。
